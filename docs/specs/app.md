# Application (APP)

Requirements that apply to the app as a whole.

## APP-001 Installable web app

shelfmark is a web app that the user can install on an Android phone.

Acceptance criteria:

- Every requirement of these specifications can be carried out in Chrome on Android, the target platform of the beta.
- The user can install the app from Chrome on Android and open it from the home screen in its own window, without the browser's address bar.

Notes:

- iOS is not a target of the beta.
- Offline use is not part of the beta.

## APP-002 Responsive layout

The app is usable on phone and desktop screens.

Acceptance criteria:

- On a phone screen in portrait orientation, every view can be used without horizontal scrolling and without clipped or overlapping controls.
- In a desktop browser window, every view can be used with mouse and keyboard, without clipped or overlapping controls.

## APP-003 Language

The app's user interface is in English.

Acceptance criteria:

- Every interface text (labels, buttons, messages) is in English.
- Data entered by the user or obtained from the book lookup is shown as it is, without translation.

Notes:

- The app is prepared for more languages; adding one is a later change.
