# Application (APP)

Requirements that apply to the app as a whole.

## APP-001 Installable web app

shelfmark is a web app that the user can install on an Android phone.

Acceptance criteria:

- The app works in Chrome on Android, the target platform of the beta.
- The user can install the app from Chrome on Android and open it from the home screen like a native app.

Notes:

- iOS is not a target of the beta.

## APP-002 Responsive layout

The app is usable on phone and desktop screens.

Acceptance criteria:

- Every view is usable on a phone screen in portrait orientation without horizontal scrolling.
- Every view is usable in a desktop browser window.

## APP-003 Language

The app's user interface is in English.

Acceptance criteria:

- Every text shown by the app is in English.

Notes:

- The app is prepared for more languages; adding one is a later change.
